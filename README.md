# Offline RAG Assistant with Microsoft Foundry Local

An offline Retrieval-Augmented Generation (RAG) assistant built with:

- Microsoft Foundry Local
- Phi-4 Mini
- Qwen3 Embedding
- Streamlit
- Python

## Features

- Local inference
- PDF question answering
- Semantic search
- Vector embeddings
- Streamlit interface

## Tech Stack

- Python
- Streamlit
- Foundry Local
- OpenAI SDK
